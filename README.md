# Military Asset Management System — Backend

Spring Boot REST API for managing military assets, inventory, purchases, transfers, assignments, expenditures, users, and multiple military bases.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security + JWT
- Spring Data JPA / Hibernate
- MySQL
- Maven
- Lombok

## Features

- JWT Authentication
- Role-Based Access Control
- Military Base Management
- Equipment & Inventory Management
- Purchases
- Transfers between bases
- Asset Assignments
- Expenditures
- Dashboard & Inventory Tracking
- User Management
- Audit Logs
- Validation & Exception Handling
